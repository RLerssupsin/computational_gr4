Hospital Database Project - Group 4

This project was developed as part of the Computational Skills module for MSc students at the University of Exeter.

Project Overview

The aim of this project was to create a fictional hospital database using MySQL. This involved designing database tables, establishing relationships between them and developing SQL queries to retrieve and manage information.

Database Features

  • Stores information on 40 hospitals, 100 doctors and 600 patients
  • Contains 30 medications and 500 prescriptions
  • Links diseases to appropriate medications and specialist doctors
  • Stores scheduled patient appointments and laboratory test results
  • Enables specific information to be retrieved across multiple tables using SQL queries
